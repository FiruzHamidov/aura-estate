# Отчёт о посещаемости для HR

`GET /api/attendance/hr-report` возвращает сводку по активным сотрудникам, `format=xlsx` — тот же расчёт в Excel. Доступ: HR, бухгалтерия и администраторы. Фильтры: обязательные `date_from`, `date_to` (до 366 дней), необязательные `branch_id`, `branch_group_id`, `role`, `search`.

Шесть колонок соответствуют предоставленному образцу: сотрудник, должность, количество рабочих дней, был, не был, без опозданий.

- Рабочие дни: график за весь выбранный период с учётом сохранённых снимков графика и назначенных дежурств. Отпуска, общие праздники и выходные исключаются, кроме назначенного дежурства в выходной.
- Был: рабочие дни со статусом `present`, `late` или `incomplete`.
- Не был: рабочие дни до сегодняшней даты с подтверждённым статусом `absent`.
- Без опозданий: явки с нулевым `late_minutes`, кроме статуса `late`.
- Дни без сводки не превращаются в отсутствие: `missing_days` выводится отдельно. Сегодня без явки и будущие даты входят в `pending_days`.

Рабочие дни = был + не был + без данных + ожидается. Все счётчики — дни, итог по сотрудникам — человеко-дни. Время расчёта определяется в часовом поясе посещаемости. Отчёт не меняет события терминалов, графики и кадровые записи.
