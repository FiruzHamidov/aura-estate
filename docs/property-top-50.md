# ТЗ: Топ-50 объектов Aura

## 11. Топ-50 объектов — дополнение от 26.11.2026

### TOP50-01. Назначение и навигация

Отдельная страница `/profile/top-50` в прежней оболочке Aura. Добавить один пункт «Топ-50» в существующую группу «Работа» рядом с объектами. Порядок остальных пунктов, верхняя и мобильная навигация сохраняются. Раздел не связан с денежным рейтингом агентов из §6.

Источник: [NED — Популярные объекты](https://admin.ned.kg/dashboard/top-50), проверен 26.11.2026. Там три подборки объектов, каждая запрашивает максимум 50 записей. NED сортирует показы по отдельному счётчику, просмотры — по числу просмотров; точные правила учёта показов и повторных просмотров NED не установлены. Правила ниже — явные определения для Aura.

### TOP50-02. Доступные объекты и права

Использовать существующие права внутреннего каталога, разрешение страницы собственных/всех объектов и существующую область own/group/public/all. Ограничения назначенных групп руководителя и скрытых филиалов сохраняются. Пользователь, имеющий доступ только к закрытым объектам, раздел не видит; сервер также запрещает запрос. Новых расширений доступа не делать.

Во всех трёх подборках только опубликованные, доступные сейчас объекты: публикация не истекла, сделка available, нет закрытия, задатка, блокирующей модерации или подтверждённого дубля. Исключить проданные, сданные, снятые, архивные, удалённые, отклонённые и черновики. Исторический период не возвращает недоступный объект. Карточки используют безопасную публичную проекцию объекта и рабочие контакты публичного агента; телефоны собственников и покупателей не отдавать.

### TOP50-03. Подборки и сортировка

| **Подборка** | **Источник и правило** | **Порядок** |
|---|---|---|
| Самые показываемые | Записи журнала показов со статусом completed по start_time в периоде, не позднее текущего времени. Отменённые, запланированные и несостоявшиеся не считать. Один ID показа = один показ, независимо от соагентов. | Количество по убыванию, затем ID объекта по возрастанию |
| Самые просматриваемые | За период — сумма ежедневной статистики views_count. За всё время — накопленный счётчик объекта. Включаются просмотры сотрудников. Существующее правило Aura: один IP + браузер для объекта в сутки; это не число уникальных людей. | Просмотры по убыванию, затем ID объекта по возрастанию |
| Срочные | Только promotion type=urgent, status=active, starts_at ≤ сейчас < ends_at. Старый listing_type без действующего продвижения не достаточен. Срочность не означает ликвидность. | Дата начала продвижения по убыванию, затем ID объекта по возрастанию |

В показах и просмотрах объекты с нулевым показателем не включать. До 50 записей без искусственного заполнения. Позиции 1–50 последовательные; одинаковый показатель разрешается стабильным ID, а не ценой или комиссией.

### TOP50-04. Периоды

По умолчанию текущий месяц. Варианты: сегодня, текущая неделя с понедельника, текущий месяц, всё время, свой диапазон. Все календарные границы — Asia/Dushanbe. Произвольный диапазон включает обе даты, до 366 календарных дней; будущие даты и обратный диапазон запрещены.

В срочных период относится к дате начала продвижения, при этом продвижение должно оставаться действующим сейчас; показать это пояснение рядом с фильтром. Дополнительный фильтр: все типы сделок / продажа / аренда. Выбор сохраняется в URL, работает после перезагрузки и возврата назад.

Для просмотров возвращать дату начала ежедневного учёта и признак complete/partial/unknown. Если выбранный период начался раньше учёта — предупредить о неполноте. Не распределять старый накопленный счётчик по прошлым дням и не выдавать неизвестную полноту за ноль.

### TOP50-05. Интерфейс

Карточки: позиция, фото либо заглушка, тип сделки, показатель выбранной подборки либо срок срочности, действующая цена и цена за м² при известной площади, название, адрес, агент и офис, ID, избранное, открытие объекта и звонок публичному агенту при наличии телефона. Денежный рейтинг агентов сюда не переносить.

Над выдачей — выбранная подборка, период, тип сделки, количество «из максимум 50», время обновления и кнопка обновления. Под выдачей — раскрываемое «Как считается Топ-50». Предусмотреть загрузку, пустую подборку, запрет доступа, ошибку и повтор. При переключении фильтров старый ответ не подменяет новую выдачу. Кэш разделять по пользователю и правам; смена аккаунта не показывает прежний результат.

На телефоне карточки в одну колонку, фильтры переносятся, горизонтального переполнения нет. Зоны касания от 44 px, видимый фокус, подписи полей, управление клавиатурой и поддержка темы Aura.

### TOP50-06. API и приёмка

GET `/api/properties/top-50?tab=shown|viewed|urgent&period=today|week|month|all|custom&offer_type=all|sale|rent`; для custom обязательны date_from/date_to. Ответ: data[], position, metric_count, urgent_since/until, property, filters, limit=50, count, as_of, data_quality, views_tracking_started_at, rules. Сортировка, фильтры, лимит и доступ выполняются сервером. Запрос не меняет объекты, показы или счётчики просмотров.

Проверить: состоявшиеся/отменённые/будущие показы; два агента у одного показа; различие дневного и накопленного счётчика; границы Душанбе; 50 из 55; равные показатели; скрытые/закрытые/дубли во всех вкладках; истёкшие/будущие/отозванные срочные продвижения; own/group и назначенные группы; отозванные права; отсутствие приватных контактов; неполный период; ошибки/повтор; сохранение URL; мобильный экран и прежняя навигация.
