# Общий каталог клиентов

Доступен стажёрам (`intern`), агентам (`agent`), РОП, МОП, администраторам и суперадминистраторам после авторизации. Отдельный read-only API намеренно показывает подходящие потребности по всем филиалам; обычные права CRM не изменены.

- `GET /api/client-catalog/counts`: число уникальных доступных клиентов и количества по подборкам. Один клиент может попасть в обе подборки, но общий счётчик учитывает его один раз.
- `GET /api/client-catalog?list=agents|interns&search=Имя&page=1&per_page=20`: страницы каталога, до 50 клиентов за запрос.
- `agents`: от 1 млн TJS на руках, новые клиенты первыми.
- `interns`: 300–800 тыс. TJS включительно, давно добавленные клиенты первыми. Нижней границы даты нет.
- Стажёрам доступна только подборка `interns`, остальным перечисленным ролям — обе.
- Только активные покупатели/совмещённые контакты, неудалённые открытые потребности с `has_cash_on_hand=true` и валютой TJS.

DTO содержит только явно перечисленные поля потребностей, имена клиента/ответственного/филиала и дату добавления. Телефоны, email, заметки CRM, meta и вложенные модели пользователя не сериализуются. В разрешённых текстовых полях имён, района и комментария маскируются стандартные записи телефонных номеров и email. Поиск допускает только буквы и разделители имени, поиск по скрытым контактам недоступен. Ответы `private, no-store`.

Раскрытие клиента показывает потребности и не меняет ответственного. Функции «забрать себе» в этом изменении нет.

## Выпуск

Согласовать выпуск с frontend-веткой `ff/shared-client-catalog`. Сначала доступный backend API, затем frontend. Миграций и переноса данных нет. После выпуска проверить авторизованное открытие каталога и реальный бейдж агентом/стажёром; гостевой запрос и чужие роли должны получать 401/403.

## Проверки

`ClientNeedPropertyTypeFilterTest` покрывает каталог, дедупликацию, права ролей, маскировку контактов, сохранение обычных прав CRM, пагинацию и старые записи первыми. Вместе с `ClientAccessTest`: 71 тест, 456 проверок. В фикстуру существующего теста прав добавлены отсутствовавшие таблицы видов ремонта, используемые текущей сериализацией ClientNeed.
